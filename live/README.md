# live

An homage to performances that have made me feel alive. Screenshots of
videos, with the sound encoded into their pixels — there are no audio files
here.

Was `amplib.app/live`, built with Parcel out of
`public-library/machines/live`. Now a static page: the only TypeScript in it
was type annotations, and Parcel was only compiling those, rewriting asset
URLs, and hashing filenames — none of which this page needs.

`index.js` drives `Stegassette.createRevealPlayer` from `../lib/stegassette.js`.
Thumbnails in `media/thumbs` are generated by the jobs pipeline.
